# Workout

GitHub Pages workout tracker. The app records weight only (no repetitions), saves locally while you train, and automatically commits `training-data.json` after all of today's exercises are marked complete and every strength exercise has a weight.

## One-time connection

Open the deployed site and enter a GitHub fine-grained personal access token once in **GitHub 连接**. Limit it to this repository and grant only **Contents: Read and write**. The token stays in that browser's local storage and is never included in the repository or deployed page source.
